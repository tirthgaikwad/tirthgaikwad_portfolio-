HOW TO USE ADVANCED FEATURES
================================================================================

PARALLAX EFFECT:
  Add data-parallax="0.5" attribute to any HTML element to make it scroll
  at a different speed. Higher value = more parallax (0.5 = 50% of scroll speed)

  Example: <div data-parallax="0.3">Your content</div>

CUSTOM TILT SPEED:
  Edit script.js line 948: change * 5 to desired rotation degrees
  Example: * 3 for subtle tilt, * 8 for extreme tilt

CHANGE PROGRESS BAR COLOR:
  Edit style.css line 1961: modify background gradient for .scroll-progress

ADJUST ANIMATION TIMING:
  Edit CSS variables in style.css top section
  --transition: controls all animation speeds (default: 0.3s)

NEED TO ADJUST SOMETHING?
================================================================================

SLOW DOWN ANIMATIONS:
  Edit style.css, find --transition variable
  Change: --transition: all 0.3s cubic-bezier(0.34, 1.56, 0.64, 1);
  To: --transition: all 0.5s cubic-bezier(0.34, 1.56, 0.64, 1);

DISABLE CARD TILT:
  Comment out this line in script.js: initCardTilt();

DISABLE PARALLAX:
  Comment out this line in script.js: initParallax();

DISABLE SCROLL PROGRESS:
  Comment out this line in script.js: initScrollProgress();

CHANGE COLORS:
  Edit CSS variables at top of style.css
  --accent-blue, --accent-purple, --accent-green, --accent-cyan, --accent-pink
